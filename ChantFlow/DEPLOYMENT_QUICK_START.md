# 🚀 ChantFlow - Deploy in 5 Minutes

Choose ONE option below and follow the steps. No credit card needed!

---

## ✨ **EASIEST: GitHub Pages (Recommended for Beginners)**

**Time: 5 minutes | Cost: FREE**

### Step 1: Create GitHub Account
- Go to [github.com](https://github.com)
- Click "Sign up"
- Fill in details (use your email)
- Click "Create account"
- Verify your email

### Step 2: Create New Repository
- Click "+" icon (top right) → "New repository"
- **Repository name:** `chantflow`
- **Keep:** Public (checked)
- **Uncheck:** "Add a README file"
- Click "Create repository"

### Step 3: Upload Files
- On the new repository page, click "Add file" → "Upload files"
- **Drag & drop ALL these files:**
  - index.html
  - app.js
  - styles.css
  - manifest.json
  - service-worker.js
  - config.json
  - .htaccess
  - README.md
  - audio folder with mp3 files

- Scroll down, click "Commit changes"

### Step 4: Enable GitHub Pages
- Click "Settings" (top menu)
- Click "Pages" (left sidebar)
- Under "Source": Select "main" branch
- **Save**
- Wait 1-2 minutes

### Step 5: Done! ✅
- Your site is live at: `https://YOUR_USERNAME.github.io/chantflow`
- Test on phone by scanning this URL as QR code
- Share the link with anyone!

## 🟢 **SIMPLEST: Netlify (Drag & Drop)**

**Time: 3 minutes | Cost: FREE**

### Step 1: Go to Netlify
- Visit [netlify.com](https://netlify.com)
- Click "Sign up" (bottom right)
- Choose "GitHub" or "Email"

### Step 2: Deploy
- Once logged in, find "Drag and drop" area
- **Drag ALL your ChantFlow files here:**
  - index.html, app.js, styles.css, etc.
  - The audio/ folder
- **Wait 30 seconds...**

### Step 3: Done! ✅
- Your site is live at a URL like: `chantflow-abc123.netlify.app`
- It's live worldwide immediately!
- You can get a custom domain for $12.99/year

## 🎯 **TRADITIONAL: Web Hosting**

**Time: 10 minutes | Cost: $1-3/month**

### Best Budget Options:
1. **Hostinger** - $2.99/month (highly recommended)
2. **SiteGround** - $2.99/month (great support)
3. **Bluehost** - $2.95/month (WordPress-friendly)

### Steps:
1. Visit hosting provider website
2. Click "Get Started" → Choose plan
3. Enter your email → Complete checkout
4. Get FTP credentials (username/password)
5. Download [FileZilla](https://filezilla-project.org) (free)
6. In FileZilla:
   - Host: `ftp.yoursite.com`
   - Username & Password: From email
   - Connect
   - Drag ChantFlow files to `/public_html`
7. Your site is live at: `https://yourdomainname.com`

## ⚠️ Troubleshooting

### Files won't upload?
- Make sure ALL files are included
- Include the audio/ folder
- Check file names (case-sensitive on Linux servers)

### Audio files not playing?
- Make sure audio/ folder is uploaded
- Check filenames in app.js match actual files
- Refresh page (Ctrl+Shift+R)

### App not installing?
- Must use HTTPS (GitHub Pages/Netlify do this automatically)
- Refresh once, wait a moment
- Check if browser has install prompt in menu

### Site looks broken?
- Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
- Clear browser cache
- Try different browser
